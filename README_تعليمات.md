# تعليمات الدمج والتشغيل

## 1. مكان الملف
انسخ `app.py` إلى مشروع Briefcase الموجود لديك في:
```
src/<اسم_الحزمة>/app.py
```
(استبدل الملف القديم إن وُجد، أو ادمج التصميم مع الكود الحالي إذا لديك شاشات إضافية).

## 2. المكتبات المطلوبة
أضف السطر التالي إلى `pyproject.toml` ضمن قسم `requires` (وقسم `[tool.briefcase.app.<appname>.android] requires` أيضاً):
```
httpx
```
ثم:
```
pip install httpx
briefcase update android -r
```

## 3. صلاحية الإنترنت على أندرويد
Briefcase يضيف صلاحية `INTERNET` تلقائياً لتطبيقات أندرويد، لكن تأكد من ذلك في:
```
src/<اسم_الحزمة>/android/gradle/app/src/main/AndroidManifest.xml
```
يجب أن يحتوي على:
```xml
<uses-permission android:name="android.permission.INTERNET" />
```

## 4. كيف يعمل التحديث "اللحظي"
- يسحب التطبيق الأسعار من `open.er-api.com` (مجاني، بدون مفتاح API) كل 60 ثانية (متغيّر `POLL_SECONDS` في أعلى الملف).
- عند كل جلب جديد، يُقارن كل سعر بالسعر السابق ويظهر:
  - سهم أخضر ▲ عند الارتفاع
  - سهم أحمر ▼ عند الانخفاض
- **ملاحظة مهمة**: مزوّدو الأسعار المجانيين (بما فيهم هذا المصدر) يحدّثون بياناتهم الفعلية عادة مرة كل 24 ساعة فقط — لا توجد تغييرات لحظية بالثانية في العملات الرسمية. التطبيق يتحقق كل دقيقة، لكنه سيعرض نفس الرقم حتى يصدر المزوّد رقماً جديداً. إذا احتجت تحديثاً أسرع فعلياً (كأسعار السوق الموازي/السوداء لليرة السورية مثلاً)، يلزم الاشتراك في مصدر بيانات مدفوع متخصص واستبدال دالة `_fetch_rates_once`.
- تُحفظ آخر الأسعار محلياً على الجهاز، فتظهر فوراً عند فتح التطبيق حتى قبل اكتمال أول اتصال بالإنترنت.

## 5. العملات المضافة
السورية، البحرينية، السعودية، الكويتية، المصرية، التركية، الأردنية، العراقية، العمانية،
بالإضافة إلى: الإماراتية، القطرية، اللبنانية، المغربية، الجزائرية، التونسية، الليبية،
اليمنية، السودانية، الأمريكي، اليورو، الإسترليني، الياباني، الصيني، السويسري.
يمكنك إضافة المزيد بسهولة عبر تعديل قاموس `CURRENCIES` وقائمة `DEFAULT_ORDER` في أعلى الملف.

## 6. ملاحظة حول اتجاه الواجهة (RTL)
مكتبة Toga لا تدعم رسمياً قلب اتجاه الواجهة بالكامل (RTL) على كل المنصات، لذلك تم الاعتماد على:
- نصوص عربية بالكامل في كل التسميات والأزرار
- محاذاة النصوص إلى اليمين حيثما أمكن
إن أردت اتجاه RTL كاملاً (قوائم وأزرار تنعكس فعلياً من اليمين لليسار كواجهات أندرويد الأصلية)، يلزم تخصيص إضافي على مستوى Android (تعديل `AndroidManifest.xml` لإضافة `android:supportsRtl="true"` وضبط `layoutDirection`)، وأنا جاهز لمساعدتك في ذلك إذا رغبت.
